# Manifesto da campanha experimental

Cada rodada deve registrar:

- identificador da rodada;
- perfil da topologia;
- arquivo de entrada;
- tamanho do arquivo;
- operação;
- nível de concorrência;
- número da repetição;
- endereço do servidor;
- porta;
- data e horário;
- comando executado;
- JSON produzido pelo cliente;
- hashes de origem, servidor e destino;
- falhas observadas;
- configuração do enlace de gargalo.

Nenhuma falha deve ser removida dos resultados brutos.

Os dados brutos não devem ser editados manualmente depois da coleta.
